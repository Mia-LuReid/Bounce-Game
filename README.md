# Bounce-Game
A simple GUI application written in python using tkinter module

# Requirements
Python 3.11.*
```
sudo dnf install python3
sudo dnf update python3
```

Python3-tkinter
```
sudo dnf install python3-tkinter
```

use the paddle to move the ball and clear all of the stationary obstacles at the top.
Press Enter to start/restart the game.
Left/Right arrow keys to move the paddle.
Spacebar to pause the game.
